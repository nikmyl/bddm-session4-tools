Key Terms

Additive Decomposition

Y = T + S + I. Seasonal swing is a fixed euro amount (e.g., July is always +€108K above trend). Works when peaks and troughs are roughly the same height over time.

Multiplicative Decomposition

Y = T × S × I. Seasonal swing is a ratio (e.g., July is always 1.72× the trend). Peaks grow taller as the trend rises — the swing scales with the level.

Residuals (Irregular)

What's left after removing trend and seasonality. If the model is correct, residuals should be random with no pattern. A fan shape signals the wrong model.

How Residuals Are Calculated

Step 1 — Trend: Compute the 12-month Centred Moving Average (CMA) to get the trend, T.

Step 2 — Seasonal indices:

  • Additive: Subtract trend from actual: D = Y − T. Average each calendar month's D values. Adjust so the 12 indices sum to zero. Units: €.
  • Multiplicative: Divide actual by trend: R = Y / T. Average each calendar month's R values. Adjust so the 12 indices average 1.0. Units: ratios.

Step 3 — Fitted value:

  • Additive: Fitted = T + S (trend plus seasonal index in €)
  • Multiplicative: Fitted = T × S (trend times seasonal ratio)

Step 4 — Residual:

  • Additive: I = Y − Fitted (in €). Positive = actual was above model.
  • Multiplicative: I = Y / Fitted (ratio). Shown as % deviation: (I − 1) × 100. E.g., +3% means actual was 3% above what the model predicted.

The Rule of Thumb

If the seasonal swings grow as the trend rises → multiplicative.
If swings stay roughly the same height → additive.

Look at the raw data first. If the peaks get taller over time, you need the multiplicative model.
